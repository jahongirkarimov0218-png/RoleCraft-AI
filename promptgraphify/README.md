# PromptGraphify

Static analyzer and graph visualizer for LLM prompts.

> **Community-built.** PromptGraphify is an independent project. It is not affiliated with or endorsed
> by Graphify Labs, and it does not use their logo or marks. It was inspired by the architecture of
> [Graphify-Labs/graphify](https://github.com/Graphify-Labs/graphify) (see `docs/REFERENCE_NOTES.md`);
> no code was copied.

Status: work in progress (see `docs/STATUS.md`). Installation and usage instructions are written when
they have been executed from a fresh clone (milestone M6).
