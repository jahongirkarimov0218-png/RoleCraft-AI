# Таск 03: Playwright E2E Suite, Cross-Browser / Responsive Verification & Production Build

> Волна: 3 · Зона: `e2e/`, `playwright.config.ts`, `test/`
> Блокирован: 02
> Блокирует: финал
> Требования: R17, R18

## Что сделать
1. Создать E2E тест в `e2e/rolecraft.spec.ts`:
   - Сценарий 1: Загрузка страницы, проверка заголовка и наличия 4 пресетов.
   - Сценарий 2: Клик по пресету ("Staff AI / LLM Architect") — проверка автозаполнения всех полей формы.
   - Сценарий 3: Запуск генерации — появление шиммер-лоадера, успешная генерация, появление Thinking Partner карточки и секций Markdown (включая 🛑 Anti-Persona и 🚀 Value Proposition).
   - Сценарий 4: 1-клик копирование Markdown — проверка тактильного изменения кнопки ("Copied!").
   - Сценарий 5: Валидация формы — отправка пустых данных вызывает сообщение об ошибке валидации без падения страницы.
   - Сценарий 6: Мобильная верстка — проверка корректного отображения и доступности на мобильном экране (375x667).
2. Прогон полного тестового набора:
   - Vitest unit-тесты (`npm test`).
   - Playwright E2E тесты (`npx playwright test e2e/rolecraft.spec.ts`).
   - Проверка `npm run build` на отсутствие ошибок компиляции и типов.

## Критерии приёмки
- [ ] Все E2E тесты проходят в Playwright.
- [ ] Все Vitest тесты зелёные.
- [ ] `npm run build` собирается без ошибок.
